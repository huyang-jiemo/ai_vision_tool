## 一、测试概述

### 1.1 测试目的

验证 v0.5.4 版本在车载影像解译、正射影像标线提取、变化比对三大功能上的正确性与稳定性，验证成果格式的可用性与双平台交付包的完整性，为版本发布提供依据。

### 1.2 测试范围

| 范围 | 内容 |
| --- | --- |
| 功能测试 | 三个工作台的完整业务流程、参数配置、进度反馈、成果输出 |
| 成果验证 | SHP / File GDB 在 ArcGIS、QGIS 中的读取，与底图、存量数据的叠合 |
| 性能测试 | 真实业务数据的处理耗时与产出规模 |
| 打包验证 | 免安装包在 macOS / Windows 双平台的构建、自检与签名 |
| 界面测试 | 布局、状态流转、交互行为的自动化回归 |

不在本版范围内：正射影像标志点提取（俯视视角牌面不可辨，规划经样本微调后补充）。

### 1.3 测试方法

| 方法 | 说明 |
| --- | --- |
| 真实数据全流程 | 以业务采集的真实数据执行端到端任务，成果人工核验 |

## 七、已知边界

以下情况为当前版本的已知边界，均已写入用户说明文档，不影响版本交付：

1. 检测模型采用通用预训练权重，对特定区域特有标志牌、异形设施召回有限；
2. 车道线提取面向结构化城市道路，无标线或严重遮挡路段可能少检或不检；
3. 正射提取采用无监督图像算法，建筑轮廓、停车位线可能进入「疑似新增」，树冠遮挡可致标线断裂并被误判「疑似缺失」，均以人工确认兜底；
4. 正射影像标志点提取暂未纳入。
