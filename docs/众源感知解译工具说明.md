# 众源感知解译工具说明

| 项目 | 内容 |
| --- | --- |
| 产品名称 | 众源感知解译工具（AIVisionTool） |
| 当前版本 | v0.5.4 |
| 运行平台 | Windows 10/11（x64）、macOS 12 及以上（Apple Silicon） |
| 交付形式 | 免安装压缩包，解压即用 |
| 成果格式 | Shapefile（SHP）、File Geodatabase（GDB）、JSON 报告、标注预览图 |

## 一、产品概述

众源感知解译工具面向城市基础设施巡检与地图更新业务，对巡检车辆采集的车载全景影像、位姿轨迹以及无人机正射影像进行自动解译，输出可直接叠加既有 GIS 系统的矢量成果，并提供与存量地图的要素级变化比对能力。

工具的核心价值体现在以下方面：

1. 以自动解译替代人工判读与手动矢量化，显著缩短单期数据处理周期；
2. 检测与提取规则统一固化在程序内，保障不同批次、不同作业人员成果口径一致；
3. 成果采用 SHP / File GDB 等通用格式，坐标系与存量成果保持一致，可直接入库；
4. 全部计算在用户本机完成，数据不出内网，满足测绘数据保密要求。

## 二、运行环境

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10/11 x64；macOS 12 及以上（Apple Silicon） |
| 硬件 | 多核 CPU，内存 8 GB 及以上；无需独立显卡，无需联网 |
| 依赖组件 | 无需安装，压缩包内含全部运行环境 |

部署方式：解压对应平台的压缩包。Windows 下双击 `AIVisionTool.exe`；macOS 下双击 `AIVisionTool.app`（首次打开如出现安全提示，请右键选择「打开」）。

## 三、功能组成

主界面由左侧功能导航与三个工作台组成：车载影像提取、正射影像提取、变化比对。每个工作台顶部提供分步操作指引，按「选择数据 → 选择输出 → 开始处理」的顺序操作即可完成一次任务。

### 3.1 车载影像提取

面向巡检车辆采集的车载全景影像与位姿轨迹，自动完成目标检测、车道线提取与地理参考。

**输入要求**

| 数据 | 内容 | 说明 |
| --- | --- | --- |
| 照片目录 | 全景相机按相机编号（CAM_x）组织的 JPG 影像 | 7360×4912 高分辨率 |
| 轨迹目录 | 与影像同批次采集的位姿文件（.hdi 等） | 提供曝光瞬间的位置、姿态、高程 |

照片目录与轨迹目录须按批次同名配对（如 `20260327_1-2（东湖路）`）。工具启动扫描后自动报告可配对影像数量，无法配对的影像在日志中提示。

**可配置参数**

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 置信度阈值 | 0.15 | 可在 0.05–0.90 间调节，阈值越低检出越多 |
| 最大影像数 | 0（不限） | 用于小批量试跑验证 |

**输出成果**（输出目录按分区管理，矢量成果为 SHP 格式）

| 成果 | 位置 | 说明 |
| --- | --- | --- |
| 目标点要素 | `shp/` | 动态障碍、交通标志、信号灯、路侧设施等类别，含类别、批次、来源影像、置信度、离车距离属性 |
| 车道线要素 | `shp/` | 点采样形式，含左右侧与所属批次 |
| 时序变化要素 | `shp/` | 同一路段多批次间目标的新增/消失 |
| 标注预览图 | `preview/` | 检测框与车道线叠加，供人工抽检 |
| 运行日志 | 输出目录 | `运行日志_时间戳.log`，含参数、逐文件明细、分类统计与汇总 |

### 3.2 正射影像提取

面向无人机正射影像（DOM/TIF），自动提取车道标线并输出地理数据库。

**输入要求**

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 正射影像目录 | — | 选择包含 DOM 影像（.tif）的目录，工具自动识别其中最大的 TIF 文件 |
| 存量 GDB | 可选 | 提供后仅处理存量图幅覆盖范围，速度与精度更优 |
| 最短标线 | 2 米 | 小于该长度的碎片自动剔除 |
| 仅提取存量道路走廊 | 开启 | 以存量线状道路要素为中心构建 ±8 米走廊，仅保留走廊内结果；道路两侧建筑物、屋顶、庭院等一律不提取 |

**输出成果**

| 成果 | 说明 |
| --- | --- |
| 正射提取.gdb | lanes（线状标线）、lane_areas（面状标线）两个图层 |
| 叠加预览图 | 提取结果与影像叠加渲染，供人工核验 |
| 运行日志 | 处理过程逐阶段记录，含原始提取、共线合并、GDB 写出等阶段进度 |

### 3.3 变化比对

将自动解译成果与存量地图做要素级比对，输出变化清单与叠加预览。

**输入要求**

| 参数 | 说明 |
| --- | --- |
| 新成果 GDB | 正射提取或车载解译生成的地理数据库 |
| 存量 GDB | 既有全要素成果 |
| 底图 TIF | 可选。提供后预览图以正射影像为底渲染 |

**输出成果**

| 成果 | 说明 |
| --- | --- |
| 变化统计 | 匹配、疑似新增、缺失、疑似改动四项总量及按类别明细表 |
| 变化预览图 | 变化要素与底图叠加渲染 |
| 变化比对.gdb | 变化要素分图层组织，附来源图层与判定原因字段 |
| 比对报告.json | 机读格式比对结果 |

比对结果自动留档至存量 GDB 同级的 `变化比对_时间戳` 目录，界面提供一键打开留档目录。比对结论为「疑似」性质，最终以人工内业确认为准，确认后并入存量库实现增量更新。

## 四、界面功能说明

**进度与队列。** 任务运行中实时显示整体进度百分比、已处理数量、预计剩余时间；车载影像提取提供逐文件状态队列，每幅影像显示等待/处理中/完成/失败状态及分类检出标签，支持按全部、成功、失败筛选。

**运行日志。** 终端风格展示，按语义着色（成功、信息、错误），逐行带时间戳，并同步写入输出目录的日志文件。

**结果展示。** 任务完成后在工作台内直接展示统计卡片、分类明细表与结果预览图；预览图支持滚轮缩放、拖动平移、双击还原，并默认铺满显示区域。

**退出确认。** 点击窗口关闭按钮时，工具先弹出系统确认提示，不会立即退出。提示中同时说明：如仍有任务正在运行，退出将中断当前任务。选择「取消」返回工作界面，选择「退出」才真正关闭程序。

## 五、技术特点

1. **目标检测**：采用 YOLO11 目标检测网络，ONNX Runtime CPU 推理，输入尺寸 1536，兼顾小目标召回率与推理速度，无需 GPU 与联网；
2. **车道线提取**：颜色掩膜、边缘门控、颜色占比评分与 RANSAC 拟合多重约束，仅输出有观测证据的线段，不向遮挡区域外推；
3. **鱼眼畸变校正**：针对全景相机广角畸变建立球面投影校正映射并缓存，逐幅重采样；
4. **地理参考**：位姿与相机模型联合解算，像素坐标反投至地面，坐标系与存量成果完全一致；
5. **大幅面正射处理**：2048 像素分块、256 像素重叠读取，局部对比度分割与路面掩膜约束，支持单幅 5 万×8 万像素的大幅面影像；
6. **要素级变化比对**：线、面、点三类要素分别采用覆盖式匹配、IoU 匹配与最近邻匹配策略，变化结论附判定原因。

## 七、常见问题

| 现象 | 处理建议 |
| --- | --- |
| macOS 首次打开提示无法验证开发者 | 右键点击 `AIVisionTool.app` 选择「打开」 |
| 车载影像数量为 0 | 检查照片目录与轨迹目录是否按批次同名配对 |
| 正射提取选择目录后无影像 | 确认目录内包含 `.tif`/`.tiff` 文件 |
| 变化比对出现大量「缺失」 | 多为树冠遮挡导致标线断裂所致，属疑似结论，请人工确认 |
| 结果区未显示预览图 | 任务完成后结果区保留单张预览图；若提示加载失败，可直接打开输出目录查看已生成的预览图文件 |
| 点关闭按钮后程序未退出 | 弹出的是退出确认提示，选择「退出」才关闭程序；选择「取消」可返回继续操作 |
| 结果与底图无法叠合 | 检查输入数据的坐标系定义，成果坐标系取自存量参考文件 |
